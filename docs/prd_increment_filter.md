# 增量 PRD：左侧表格筛选 + Assign to me

> 所属项目：plan-gantt（PM 甘特图工具）
> 增量编号：U03

### 变更记录
| 日期 | 版本 | 说明 |
|------|------|------|
| 2026-09-03 | v1 | 首版：表头下拉筛选 + Assign to me |

## 1. 增量需求

### 1.1 原始需求

> 「让我们把左边的表格区域增加 filter 功能，同时增加一个按钮叫 'assign to me'，当点击时，计划将只显示与我有关的内容，'我' = 登录时选择的人，责任人和顾问有 '我' 都算」

拆成两件事：
1. 左侧表格区域增加 **filter（筛选）** 功能；
2. 新增 **「Assign to me」** 按钮：点击后只显示与「登录人」有关的内容 —— 负责人或顾问人里含有登录人，**任一命中即算**。

### 1.2 需裁定的三个设计点（用户已裁定）

| 设计点 | 用户裁定 |
|--------|----------|
| filter 形态 | **Excel 风格表头下拉筛选**（每列表头带漏斗，点开是该列专属筛选） |
| 命中子任务时父任务是否显示 | **显示匹配行 + 祖先链**（WBS 树不断链，父任务即使不匹配也一并显示，仍可折叠） |
| 筛选条件是否记忆 | **不记忆**（刷新/切换计划即重置，避免「打开一片空白」的困惑） |

### 1.3 不在本次范围

- 筛选条件的持久化（按裁定不记忆）。
- 「保存筛选为视图」之类的高级功能。
- 甘特图条本身的独立筛选（甘特图与表格共用同一份过滤结果，天然同步）。

## 2. 行为细则

### 2.1 筛选交互（P0-1）

- 表头除「行号」「操作」外，其余 7 列（任务名称 / 开始 / 结束 / 时长 / 依赖 / 负责人 / 顾问人）表头右侧加**漏斗图标**；该列有激活筛选时漏斗高亮（蓝色）。
- 点漏斗弹出该列专属菜单：
  - **枚举列**（负责人 / 顾问人 / 依赖 / 时长）：搜索框 + 全选 + 值勾选列表 + 「(空白)」项（勾选可筛出该列为空的行）。
  - **文本列**（任务名称）：条件下拉（包含 / 不包含 / 开头是 / 等于）+ 关键词输入。
  - **日期列**（开始 / 结束）：条件下拉（早于 / 不早于 / 晚于 / 不晚于 / 介于）+ 日期输入。
- 勾选/输入**即时生效**，无需点「确定」。菜单底部可「清除本列筛选」。
- 多列筛选之间是**同时满足（AND）**。

### 2.2 Assign to me（P0-2）

- 表格顶部工具条一个切换按钮「Assign to me」：激活后只保留「负责人或顾问人里含有登录人」的行（含祖先链），大小写不敏感。
- 再点一次取消，恢复全部行。
- 登录人来自「登录时选择的人」（`session.user`）；与列筛选是 **AND** 关系（先 Assign to me 再叠加列筛选）。

### 2.3 祖先链（P0-3）

- 命中的子任务的所有祖先（父、祖父……直到根）一并保留，即使祖先本身不匹配，保证 WBS 树不断链。
- 祖先保留不影响折叠行为：仍可按折叠状态隐藏其子孙。

### 2.4 计数与清除（P0-4）

- 工具条常显「显示 N / 共 M 行」。
- 已激活的列筛选以 **chips** 形式显示在工具条，可单项清除；另有「清除全部」一次清空列筛选 + Assign to me。

### 2.5 过滤态下的编辑约束（P0-5）

- 过滤激活时「新增一行」（底部按钮 + 行内插入按钮）禁用，避免在「看不到的行之间」插入造成困惑。清除筛选后恢复。
